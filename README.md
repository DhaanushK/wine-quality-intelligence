\# Wine Quality Intelligence



\## Project Overview



Wine Quality Intelligence is a data analytics project that explores global wine reviews, critic ratings, listed prices, countries, regions, grape varieties, and wineries.



The project uses Python, MySQL, and Power BI to transform raw wine review data into meaningful analytical insights and interactive dashboards.



\## Objectives



\- Analyze global wine review and rating distributions.

\- Explore relationships between wine prices and critic ratings.

\- Compare wine pricing and ratings across countries and regions.

\- Identify affordable, highly rated wines and varieties.

\- Examine regional value positioning and rating consistency.

\- Build interactive dashboards for data-driven exploration.

\## Dataset



\*\*Wine Enthusiast Wine Reviews Dataset\*\*



Source: \[Kaggle – Wine Reviews](https://www.kaggle.com/datasets/zynicide/wine-reviews)



The original dataset contains approximately 150,930 wine review records.



The deduplicated analytical dataset contains 97,851 records.



The dataset is not included in this repository. Download it from the source and place it in the appropriate local data directory.



\## Key Analytical Findings



\- 97,851 records in the deduplicated dataset.

\- 48 countries represented.

\- 632 wine varieties represented.

\- Average critic rating: 87.96.

\- Average listed price: $33.66.

\- 8,912 affordable, highly rated review records (price ≤ $30 and rating ≥ 90).



These findings describe the dataset and should not be interpreted as direct measures of wine sales or consumer demand.
